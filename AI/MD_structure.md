# Заголовок первого уровня (H1)

Добро пожаловать в универсальное руководство по **Markdown** — легковесному языку разметки, который позволяет создавать структурированные документы с помощью простых текстовых символов.

## Заголовок второго уровня (H2)

В этом разделе мы рассмотрим базовые стили текста и форматирование.

### Заголовок третьего уровня (H3)

Здесь мы углубимся в списки и цитаты.

---

### 1. Текстовые стили и выделения

Обычный абзац может содержать **жирный текст**, _курсив_, а также **_жирный курсив_**. Для устаревших данных используется ~~зачеркнутый текст~~. Внутри строки удобно оформлять `упоминания кода` или переменные. Если нужно сделать акцент, можно использовать подчеркивание через HTML-теги: <u>подчеркнутый текст</u>.

### 2. Списки

Структурировать информацию помогают списки двух основных типов:

- Маркированный список:
  - Первый элемент уровня;
  - Второй элемент с вложенностью:
    - Подпункт А;
    - Подпункт Б.

1. Нумерованный список:
   1. Шаг первый: подготовка данных.
   2. Шаг второй: обработка скриптом.
   3. Шаг третий: сохранение результата.

Интерактивные списки задач (Task Lists):

- [x] Установить редактор кода;
- [x] Изучить синтаксис Markdown;
- [ ] Опубликовать документ в репозитории.

### 3. Цитаты

> «Простота — залог надежности в инженерии и текстах».
>
> > Вложенные цитаты позволяют делать примечания или оформлять диалоги внутри документа.

### 4. Блоки кода

Для демонстрации программного кода используются тройные обратные кавычки с указанием языка:

```python
def calculate_sum(a, b):
    # Возвращает сумму двух чисел
    return a + b
```

### 6. Таблицы

Таблицы отлично подходят для сравнения параметров и характеристик:

### 7. Сноски и экранирование

Вы можете добавлять сноски для пояснений по ходу чтения[^1], а также экранировать спецсимволы с помощью обратного слэша, например: \*это не курсив\*.

[^1]: Это текст сноски, который обычно автоматически переносится в самый низ страницы.
