Первая часть (работа с VM и count):
1. Создайте ресурсную группу.
2. Настройте виртуальную сеть и одну подсеть.
3. Разверните 3 виртуальные машины Ubuntu 20.04:
    - Используйте count для создания всех необходимых ресурсов (NIC, public IP, VM, диски).
    - Используйте переменные для имени, региона, имени пользователя и пароля.
    - Названия ВМ и дисков должны быть уникальными, например: student-vm-0, student-vm-1, student-vm-2.
4. Добавьте NSG с правилом для порта 22 и примените его к каждому NIC.

Вторая часть (добавление подсетей):
1. В файле locals.tf (или main.tf) определите следующую карту подсетей:
locals {
  subnets = {
    frontend = "10.0.1.0/24"
    backend  = "10.0.2.0/24"
    dmz      = "10.0.3.0/24"
  }
}
2. Создайте подсети внутри ранее созданной VNet с помощью for_each по local.subnets.

Третья часть (работа с output и for):
1. Добавьте вывод списка публичных IP-адресов ВМ:
output "public_ips" {
  value = [for ip in azurerm_public_ip.pip : ip.ip_address]
}
2. Добавьте вывод имён ВМ:
output "vm_names" {
  value = [for vm in azurerm_linux_virtual_machine.vms : vm.name]
}
