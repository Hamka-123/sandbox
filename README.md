# 🧪 Engineering Sandbox

A personal sandbox for **hands-on engineering practice, technical experiments, and infrastructure exploration**.

This repository contains small projects, proof-of-concepts, experiments, labs, and exercises created while learning new technologies and exploring different engineering approaches.

Unlike my standalone projects and reusable tools, the contents here are intentionally **diverse, experimental, and independent from each other**.

---

## 🔬 Areas of Exploration

Current areas include:

* 🐹 **Go**
* 🐍 **Python**
* 🐚 **Bash & Linux**
* 🪟 **PowerShell**
* 🐳 **Docker & Containers**
* ☸️ **Kubernetes & Orchestration**
* 🏗️ **Terraform / Infrastructure as Code**
* ⚙️ **Ansible / Configuration Management**
* 🚀 **GitHub Actions & CI/CD**
* 📊 **Monitoring, Observability & Performance**
* 🌐 **Web Applications**
* 🔧 **Infrastructure Automation**
* 🛠️ **Developer Tooling**
* 🌿 **Git & Version Control**

The repository is intentionally diverse. Some experiments focus on a single technology, while others combine several tools to explore a specific engineering problem.

---

## 🎯 Purpose

The goal is to continuously build and maintain **hands-on technical skills** through experimentation and practice:

> **Learn → Build → Test → Investigate → Improve**

Experiments may be created to:

* understand how a technology works;
* test a particular approach;
* build a small proof of concept;
* reproduce and investigate a technical problem;
* practice infrastructure and automation;
* explore system behavior and performance;
* experiment with monitoring and observability;
* try a new tool or engineering workflow.

Some experiments may later evolve into standalone projects or reusable tools. Others are intentionally kept small.

---

## 🧭 From Experiment to Tool

When an experiment becomes useful beyond the original learning task, it may evolve into a reusable tool or a standalone project.

```text
Question
   ↓
Experiment
   ↓
Learn
   ↓
Build
   ↓
Test / Evaluate
   │
   ├── Keep experimenting
   │
   ├── Turn into a reusable tool
   │
   └── Evolve into a standalone project
```

Reusable tools are maintained separately in [`DevOps Tools`](https://github.com/Hamka-123/Devops_tools), while larger engineering solutions live in their own repositories.

---

## 🧪 Engineering Philosophy

This repository is intentionally a **sandbox, not a portfolio of polished products**.

The focus is on:

* getting hands-on with technologies;
* understanding systems by building and testing them;
* experimenting with different engineering approaches;
* investigating failures and unexpected behavior;
* turning experiments into practical solutions when they prove useful.

Not every experiment is expected to become a finished project — **the value is in the exploration and the engineering practice itself**.
